# Quran data

Generated by `npm run quran:import` from the [`quran-json`](https://github.com/risan/quran-json) package (v3.1.2). Do not edit these files by hand; the text must stay exactly as published.

- **Arabic text:** the Uthmani script of the King Fahd Glorious Qur’an Printing Complex (Madinah), as published by [The Noble Qur’an Encyclopedia](https://quranenc.com/).
- **English meaning:** Saheeh International, as distributed by [Tanzil.net](https://tanzil.net/trans/en.sahih). Tanzil allows use with attribution and without changes to the text.
- **Dataset:** compiled by Risan Bagja Pradana and shared under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). These derived files are shared under the same license.

Each `N.json` holds surah `N` as `{ id, verses: [[arabic, english], ...] }`. `surahs.json` lists the 114 surahs with their names and ayah counts. The import checks that all 6,236 ayahs are present.
